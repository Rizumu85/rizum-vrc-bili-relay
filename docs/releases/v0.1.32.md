# v0.1.32 — 过期会话与列表加载状态修复

本版修复两个已定位的问题，没有扩大到新的媒体架构重写。

- 停止中继后旧会话过期，不再让后续“生成地址／重试”卡在旧会话的停止请求上。
  只有同一 worker 明确确认会话不存在才释放对应记录；临时错误仍按未知状态处理。
- 收藏夹快速切换并命中缓存时，不再遗留“正在加载”状态。
  收藏夹首页、视频页以及稍后再看／历史共用请求所有者，旧回包不能修改当前列表。
- 追加有容量上限的本地诊断事件，记录会话确认消失、列表请求开始／完成／取消／丢弃。
  默认不增加账号、Cookie、推流密钥、链接或列表内容的日志。

媒体时间轴、ASS 绑定、编码参数、账号存储和设置格式保持不变。
缓存重新验证期间会暂时禁用加载更多；重新验证失败仍可保留已有缓存列表。

验证范围与对照结果见 docs/state-boundary-audit.md；Release 附带
state-boundary.json、ui-state.json、worker-roundtrip.json、media-pipeline.json、
ass-clock.json 和精确 ZIP 校验记录。模拟过期／列表时序不等同于真实原生窗口
或 B 站 → VRCDN → VRChat 的端到端验收。

关闭旧版后，将便携包完整解压到新的空文件夹再运行。未远程替换用户正在运行的程序。
